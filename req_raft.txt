# req_raft.txt — Python deps for **Path B** (the RAFT track): the hand-rolled
# hybrid RAG (src/legal_explainer/finetune/raft_rag/) + RAFT QLoRA training via
# Unsloth (scripts/train_unsloth.py). Lives in its own conda env so Unsloth's
# pinned versions don't disturb the main `legalpolicy` env.
#
# Recreate the env:
#     conda create -n RAFT -y python=3.11
#     conda activate RAFT          # (or use /path/to/envs/RAFT/bin/pip)
#     pip install -r req_raft.txt
#
# Notes:
#   * `torch==2.10.0` resolves to the cu128 build from PyPI (linux default);
#     verified working with NVIDIA driver 581.86 on an RTX 3050 6 GB (WSL2).
#     Unsloth 2026.5.2 requires torch >= ~2.10, which is why we're on cu128 here
#     rather than the cu121 build the `legalpolicy` env uses.
#   * Import order matters at runtime: `import unsloth` must come before
#     transformers/trl/peft — scripts/train_unsloth.py already does this.
#   * For the absolute full lock (every transitive dep), use `pip freeze`.
